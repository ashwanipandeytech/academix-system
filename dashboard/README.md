# Academix SaaS Dashboard

A production-ready School Management SaaS Dashboard frontend built with Bootstrap 5.3 and SCSS.

## Tech Stack
- HTML5 / JS (ES6+)
- Bootstrap 5.3+
- SCSS (Modular architecture)
- Vite (Build tool)

## Project Structure
- `assets/scss/`: Variables, mixins, components, and themes.
- `assets/js/`: Modular JavaScript for auth and UI interactions.
- `index.html`: Dashboard overview page.
- `login.html`: Authentication page with role selection.

## Getting Started
1. Navigate to the `dashboard` directory.
2. Install dependencies: `npm install`.
3. Run development server: `npm run dev`.
4. Build for production: `npm run build`.

## Features (Phase 1)
- Sidebar with collapsible state.
- Topbar with dark mode toggle and user profile.
- Responsive layout (mobile-first).
- Mock authentication with role-based storage.
- Modern SaaS UI with gradient-based theme.
